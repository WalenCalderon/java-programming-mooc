# Java Programming MOOC

Este repositorio contiene mis soluciones de los ejercicios del **Java Programming MOOC** de la Universidad de Helsinki.

## Progreso

- Parte 1: completada y aceptada por TMC (37 ejercicios)
- Parte 2: ejercicios 01-20 aceptados por TMC; 21-34 pendientes

El estado de validación y envío a TMC se mantiene por separado en
[docs/TMC-SUBMISSION-STATUS.md](docs/TMC-SUBMISSION-STATUS.md). Que una
solución esté completada en este repositorio no implica que ya haya sido
aceptada por el servidor.

Los ejercicios están organizados por parte y conservan su estructura original de Maven y los archivos necesarios del sistema de ejercicios TMC.

## Aviso

Este repositorio tiene fines exclusivamente educativos y documenta mi progreso personal en el curso.
